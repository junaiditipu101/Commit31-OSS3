# Commit31-OSS3 (UniFind)

An open-source Lost & Found platform for college campuses that helps students report lost items, post found belongings, and securely reconnect owners.

---

## ✨ Features

- Post lost items
- Post found items
- Secure ownership claim system
- Campus verification login
- Smart matching system

---

## 🛠 Tech Stack

- Frontend: React
- Backend: FastAPI
- Database: PostgreSQL
- Styling: Tailwind CSS
- CI/CD: GitHub Actions

---

### 1. Clone the repository

git clone https://github.com/LinuxCampusClubSJCE/Commit31-OSS3.git

### 2. Navigate to project directory
